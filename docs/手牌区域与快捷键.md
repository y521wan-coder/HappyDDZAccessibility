## 识别路线

大厅、公告和弹窗仍用整窗口 OCR，以便读公开文字并建立坐标。牌桌手牌改用底部区域：当前已观察到的 1280×720 回放画面中，手牌约在 x=200～1080、y=531～606，卡间距约 41 像素。快速刷新只抓两帧并运行这块区域的牌角模板识别，不再跑整窗口 OCR；最近一分钟内必须先有一次完整扫描确认场景和版本。尺寸、窗口或两帧牌数变化时清空候选。

在同一张历史回放图上预热后测得 CPU OCR 中位数（3 次，单位毫秒）：

| 检测+识别模型 | 手牌裁区 780×90 | 整帧 1280×720 | 裁区识别文字 |
| --- | ---: | ---: | --- |
| tiny+tiny | 234.8 | 257.9 | `2455!:99833933#` |
| tiny+small | 235.0 | 440.0 | `QAAKK11Y987779544` |
| small+small | 861.2 | 715.4 | `元Or / 4` |

该图真实手牌有 17 张，重叠牌角导致 OCR 字符串无法可靠分牌、识别花色或大小王。局部 OCR 仍需逐张牌角校验才能参与动作；当前保留 tiny+tiny 供整窗口导航，手牌采用双帧模板候选。双帧牌角候选器在同一张缓存图上 5 次调用的中位数约 316 毫秒，不含窗口捕获和进程启动；这是单局样本的速度测试，不是准确率或实时倒计时证明。

## 手牌列表按键

聚焦助手的“手牌”列表后使用：

| 按键 | 当前行为 |
| --- | --- |
| 左／右 | 按未拿起点数组浏览 |
| Home／End | 首组／末组 |
| 上 | 本地预览拿起当前一张；再次按上可找下一张未拿起牌 |
| Ctrl+上 | 本地预览拿起当前点数的未拿起牌；点数未知时拒绝整组 |
| 下 | 当前牌已拿起就放下当前牌，否则按拿起先后顺序放下一张 |
| Ctrl+下 | 本地预览全部放下 |
| 回车／Ctrl+回车 | 分别提示出牌／过牌尚不可提交，不向游戏发送输入 |

拿放结果、已拿起状态和拒绝原因写在有 UIA 名称的状态文本框与列表项中。刷新或窗口切换清空本地选择；选牌键忽略持续按住时的重复 KeyDown。`Tab` 可到快速刷新、上一组、下一组、拿起一张、拿起整组、放下一张、全部放下按钮，热键不是唯一入口。

飞船的“端点补顺子/连对”和牌型播报依赖可信牌面与规则模型；本项目现在只处理候选牌，不启用自动补牌。腾讯游戏的单张拿放已有受限实验模式，整组、多张同时选中和 20 张地主游戏内点击还需现场验证。没有独立牌局验证前，回车出牌、过牌和抢地主保持禁用；本人“叫地主／不叫”的受限入口见本文件末尾。
