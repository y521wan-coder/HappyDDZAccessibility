# 决策日志

| 日期 | 决策 | 证据与原因 | 影响与回退 |
| --- | --- | --- | --- |
| 2026-10-02 | 项目根目录设为 `D:\HappyDDZAccessibility` | 用户要求 D 盘英文目录及交接说明 | 所有源码、工具、样本、文档和依赖副本在该目录；完整移动目录即可迁移 |
| 2026-10-02 | 用 .NET 10 x64 WinForms 做只读壳原型 | 本机 SDK/桌面运行时存在；官方文档支持 Win10 LTSC/Enterprise，WinForms 标准控件提供可访问属性；本机 UIA 自动检查通过 | 争渡真人测试尚未完成，框架未作为最终不可逆锁定；必要时改 Win32 标准控件 |
| 2026-10-02 | 按窗口捕获采用 Windows Graphics Capture C++/WinRT helper | `PrintWindow` 黑帧；WGC 本机能在遮挡下抓取 1280×720 客户区 | 最小化/黑帧停止扫描；可回退前台屏幕区域截图，但前台条件受限 |
| 2026-10-02 | OCR 默认 CPU tiny+tiny | 同一真实牌桌 CPU 中位 319.5 ms，DML 中位 1528.0 ms | 设置可切换 DML 复测；不能把自制文字图基准当牌桌结果 |
| 2026-10-02 | 牌局中的选牌、出牌、过牌、叫地主保持禁用 | 一手牌样本不足，整手牌/花色/轮次没有准确率证据 | 完成独立标注与状态机后逐项开放，失败时继续只读 |
| 2026-10-02 | 排位只采样一次 | UI 显示“免费玩”但消耗 1 生命值；金币未观察到减少 | 不自动进入更多局，先确认资源规则和采样方式 |
| 2026-10-02 | OCR 会话在辅助程序存活期间复用，场景读取需连续两帧一致 | RapidV6 只能串行调用，首轮初始化增加延迟；单帧易受动画干扰 | 扫描序列加锁；关闭程序时等待本轮结束并销毁引擎；后续仍须正式状态机 |
| 2026-10-02 | 捕获组件使用进程 ID 加窗口句柄定位，并排除鼠标光标 | 避免同进程其他窗口与光标遮挡牌角；本机 API 支持 | 句柄失效或最小化时停止扫描；不向其他窗口发送输入 |
| 2026-10-02 | 将已采样的超时离房提示列为已知弹窗 | 用户提供 OCR 文字与实时两帧扫描均含“太久没操作”“确定”；背景结算文字残缺 | 先读弹窗摘要与按钮，分数标为未确认；不自动点击 |
| 2026-10-02 | 将 `D:\RapidV6_OCR` 和 `D:\Tencent` 移入项目根目录，`D:\HappyDDZ` 保持原位 | 用户要求整理 D 盘并明确游戏目录不移动；前者含开发计划和 OCR 原始包，后者仅有 QQ 游戏下载包缓存 | 辅助程序继续使用 `vendor/RapidV6`；旧的两个根目录现不存在，QQ 游戏以后可能重建下载缓存目录 |
| 2026-10-02 | 开放经现场核对的大厅与游戏导航点击 | 用户明确要方向键浏览 OCR、回车点击；大厅和游戏可按窗口捕获并 OCR | 只对已核对的进程、版本、场景和目标开放；每次重扫核对后单击，失败不重试；收费、未知弹窗和牌局动作仍暂停 |
| 2026-10-02 | 通用 OCR 文字默认只读，不能仅凭文字中心任意点击 | 装饰文字、广告、弹窗背景和重叠目标会使中心坐标不是按钮；曾把斗地主入口尾字错识为“員” | 新目标需实测区域与后果后再开放；列表保留文字和坐标供读屏浏览 |
| 2026-10-02 | 场次使用自定义 WinForms 确认框，取消为默认焦点 | 系统 MessageBox 在模态调用的 UIA 测试里只显示 Pane；自定义窗体独立检查可见 Edit、Button 和 Invoke | 自动化不确认进入可能影响豆子的场次；用户明确确认后才发送一次点击 |
| 2026-10-02 | 把周年庆红包 X 说明为“领取并关闭” | 现场点击 X 后自动领取 1000 限时钻石，不能称单纯关闭 | 后续遇相似弹窗须核对实际后果；不把领取行为当购买 |
| 2026-10-02 | 暂不更新客户端 | 游戏画面仍为 8.057.106.17343；更新公告不是可安装包证据，尚无可信更高官方 PC 版本 | 继续使用当前版本校验；找到官方更新再核对并执行，更新后暂停旧布局输入 |
| 2026-10-02 | 用已结束对局回放继续采样 | 战绩页有回放，可暂停逐步查看同一局，未触发新匹配或资源消耗 | 只收集匿名本人手牌行作开发样本；原始回放含身份信息，保存在 `samples/private` |
| 2026-10-02 | 牌角模板只读接入，出牌继续禁用 | 同一局跨玩家大小牌角匹配虽好，但一张花色原始误判；无跨对局或选中态准确率 | 双帧稳定布局、分数与差距阈值，不确定显示“未知”；任何候选都不授权游戏动作 |
| 2026-10-02 | 回放布局要求固定卡宽、牌距、居中和两帧一致 | 33 帧中 4 帧为动画/无牌，宽度不符；把过渡帧当稳定手牌会错位 | 对尺寸变化或无模型只读暂停，清除旧候选 |
| 2026-10-02 | 个人资料隐私提示选择“否” | 防止默认向其他玩家公开账户战绩/荣誉；游戏反馈“其他玩家不可查看” | 该选择可能持久，交接中明确告知用户；如需改动在游戏个人信息设置中检查 |
| 2026-10-02 | 不用 Esc 关闭游戏活动弹窗 | 回归礼遇弹窗上按 Esc 使游戏最小化，弹窗仍在 | 恢复窗口后逐个核对图形 X；后续适配需逐类记录点击后果 |
| 2026-10-02 | 只对已确认回放控制条加入图形按钮 | 历史回放的上一步/下一步/播放暂停没有稳定 OCR 文字，但底部绿色控制条可双帧验证 | 用户仍须逐项按回车；第 0 手不显示上一手，末手不显示下一手；其他场景不暴露这些坐标 |
| 2026-10-02 | 游戏前台稳定等待从 120 ms 增至 400 ms，点击后保留 450 ms | 初次助手点击回放下一手虽通过窗口校验但画面未变；手动点击同坐标有效。延长等待后助手点击从第 1 手到第 2 手成功 | 稍增操作延迟，避免焦点刚切换时游戏漏收；失败仍不自动重试 |
| 2026-10-02 | 目标窗口默认自动选择，并在大厅入口点击后连接游戏窗口 | 用户需要从 QQ 大厅顺畅进入游戏；游戏启动后大厅可能最小化，继续重扫大厅会报失败 | 已运行游戏时现场验证自动切换并朗读回放场景；若游戏未出现，仍保留大厅扫描结果及明确失败反馈 |

依赖证据：

- [微软 .NET Windows 支持说明](https://learn.microsoft.com/dotnet/core/install/windows)：Windows 10 仅限 LTSC/Enterprise 版本支持。
- [微软 WinForms 控件无障碍信息](https://learn.microsoft.com/dotnet/desktop/winforms/controls/provide-accessibility-information)：AccessibleName 等属性。
- [微软 CreateForWindow](https://learn.microsoft.com/windows/win32/api/windows.graphics.capture.interop/nf-windows-graphics-capture-interop-igraphicscaptureiteminterop-createforwindow)：最低 Windows 10 1903。
- [微软 CreateFreeThreaded](https://learn.microsoft.com/uwp/api/windows.graphics.capture.direct3d11captureframepool.createfreethreaded)：本机使用的无 DispatcherQueue 帧池。
- [微软 IsCursorCaptureEnabled](https://learn.microsoft.com/uwp/api/windows.graphics.capture.graphicscapturesession.iscursorcaptureenabled)：Windows 10 2004 起支持，19044 可关闭光标捕获。
